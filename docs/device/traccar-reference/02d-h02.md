# 2d. H02 / H08

> **Referensi Traccar:** `H02ProtocolDecoder.java` (500+ lines)

## Frame Structure

Protokol H02 mendukung dua mode: text (asterisk-prefixed) dan binary (dollar-prefixed).

### Text mode
```
*<IMEI>,<Command>,<Data...>#
```

### Binary mode
```
$<IMEI>,<Length>,<Command>,<Binary Payload><Checksum>
```

## Text Mode Commands

| Type | Command | Deskripsi |
|------|---------|-----------|
| V0 | Heartbeat | Device heartbeat |
| HTBT | Heartbeat alt | Heartbeat alternatif |
| NBR | LBS report | Cell tower info |
| LINK | Link report | Connection info |
| V3 | Position | GPS position report |
| VP1 | Position alt | Position alternatif |
| SMS | SMS report | SMS from device |

## Text Mode Position Format (V3)

```
*<IMEI>,V3,<yyyyMMddHHmmss>,<A/V>,<lat>,<N/S>,<lon>,<E/W>,<speed>,<course>,<status>#
```

## Binary Mode Position Format

```
$<IMEI>,<Length>,<0x10>,<timestamp><lat><lon><speed><course><status><checksum>
```

- Timestamp: 6 byte BCD
- Latitude: 4 byte (degrees * 30000)
- Longitude: 4 byte (degrees * 30000)
- Speed: 1 byte, km/h
- Course: 2 byte

## Status Flags (binary)

| Bit | Meaning |
|-----|---------|
| 0 | Vibration alarm |
| 1 | SOS alarm |
| 2 | Overspeed alarm |
| 10 | ACC status |
| 19 | Power cut alarm |

## Key Implementation Notes

1. Dua marker: * untuk text, $ untuk binary
2. Text mode: delimiter , (koma), akhir dengan #
3. Binary mode: length byte menentukan payload size
4. Heartbeat response: kirim balik tanpa mengubah
5. LBS mode (NBR): MCC, MNC, LAC, Cell ID
6. BCD encoding untuk koordinat di binary mode
